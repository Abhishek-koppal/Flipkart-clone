# Flipkart Clone - Frontend

## Features

- Home page with product listings and banners
- Product search and filtering
- Product detail pages
- Add to cart / Remove from cart
- Checkout flow
- Fully responsive design (mobile + desktop)

## Getting Started

### Prerequisites

- Node.js (v14 or above)
- npm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/flipkart-clone.git
cd flipkart-clone

# 2. Install dependencies
npm install

# 3. Start the development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

---

## Available Scripts

### `npm start`
Runs the app in development mode with hot reloading. Lint errors will appear in the console.

### `npm test`
Launches the test runner in interactive watch mode.

### `npm run build`
Builds the app for production into the `build/` folder. The output is minified and optimized for best performance — ready to deploy.

### `npm run eject`
>  One-way operation. Once you eject, you can't go back!

Exposes the underlying Webpack, Babel, and ESLint configuration for full manual control. Only do this if you need advanced customization.

## 🌐 Deployment

Build the app for production:

```bash
npm run build
```

You can deploy the `build/` folder to any static hosting platform:
- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)
- [GitHub Pages](https://pages.github.com/)
